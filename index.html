The PID Equation
e(t) = target − altitude
u(t) = Kp · e(t) + Ki · ∫e(t)dt + Kd · de(t)/dt
P reacts to the error right now: how far off target are we?
I reacts to error accumulated over time: the area under the error curve. It remembers past mistakes.
D reacts to how fast the error is changing: the slope of the error curve. It anticipates the future.

What the Code Actually Runs
error = target - altitude integral = integral + error * dt // clamped to +/- 50 derivative = (error - prev_error) / dt thrust = Kp*error + Ki*integral + Kd*derivative
